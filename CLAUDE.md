# Personal Workout Strategy

A personalised health app for Amol and his spouse. The full spec lives in `context/`.

- Start with `context/skills.md` (the hub); it links to every page spec in `context/pages/` and to `architecture.md`, `data-model.md`, `conventions.md` and `roadmap.md`.
- Follow `context/conventions.md` when writing code or docs.
- Check `context/roadmap.md` for what's done and what's next; tick items off as they're completed.
- When functionality, structure or technical decisions change, update the relevant context file(s) and add a dated line to the hub's change log. Keep the links between files intact.
- All other Markdown files belong in `context/`.
